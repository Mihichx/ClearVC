# ClearVC Framework (v3.2.0-LTS)

**ClearVC** — это ультра-легкий, быстрый и безопасный PHP-микрофреймворк, построенный по строгой архитектурной схеме **View-Controller (VC)**. Он изолирует системную логику от HTML-верстки, предоставляя разработчику чистый каркас для быстрого развертывания веб-приложений без привязки к жестким моделям данных.

Главная особенность архитектуры — **бронированное ядро**, которое автоматически защищает начинающего разработчика от XSS-атак, CSRF-угроз и удаленного выполнения кода (RCE), сохраняя порог входа минимальным.

## Архитектура и безопасность окружения

Фреймворк ClearVC использует концепцию **изолированного веб-корня**. Сервер (Apache, Nginx или Docker) настраивается так, чтобы его корень смотрел строго в папку `/public`. 
Благодаря этому системный код ядра, конфигурации с паролями и контроллеры физически находятся «снаружи» интернета, что делает их недосягаемыми для прямых атак.

### Жизненный цикл запроса:
1. Все запросы принимает файл `public/index.php`. Он инициализирует безопасные сессии с флагами `HttpOnly` и `SameSite=Lax`.
2. Компонент **`Request.php`** перехватывает входящие данные и рекурсивно очищает массивы `$_GET` и `$_POST` от вредоносных скриптов, предотвращая XSS.
3. **`Router.php`** сопоставляет чистый URI с картой маршрутов и безопасно прокидывает объекты `$db` и `$request` внутрь вызываемого Контроллера.
4. Любой сбой в коде или вызов `throw new \Exception()` перехватывается классом **`ErrorHandler.php`**, скрывая системные пути на продакшене.

## Алгоритм настройки и использования

### Шаг 1. Инициализация и запуск окружения

Фреймворк использует автозагрузку классов по стандарту PSR-4.

1. Скачайте проект и выполните в корне команду для установки автозагрузчика:
   ```bash
   composer install
   ```
2. **Локальный запуск (Рекомендуемый):** Запустите быстрый встроенный сервер PHP одной командой без настройки Apache:
   ```bash
   php -S localhost:8000 -t public
   ```
   *Сайт будет доступен по адресу `http://localhost:8000`.*
3. **Настройка БД:** Скопируйте `config/config.example.php` в `config/config.php` и укажите доступы к MySQL.

### Шаг 2. Создание файла логики (Controller)

Создайте класс в папке `controllers/`. Базовый класс ядра автоматически передает в ваше распоряжение объект безопасной базы данных `$this->db` и объект очищенного запроса `$this->request`.

```php
<?php
// Файл: controllers/AboutController.php

namespace App\Controllers;

use Core\Controller;

class AboutController extends Controller
{
    public function about()
    {
        $aboutData = null;

        if ($this->db !== null) {
            // Используем подготовленные запросы PDO для защиты от SQL-инъекций
            $stmt = $this->db->query("SELECT * FROM site_info LIMIT 1");
            $aboutData = $stmt->fetch();
        }

        // Передаем данные в рендер страницы views/about.php
        $this->render('about', [
            'title' => 'О компании',
            'js'    => 'slider.js, script.js',
            'info'  => $aboutData
        ]);
    }
}
```

### Шаг 3. Создание представления (View)

В папке `views/` создайте файл отображения (например, `about.php`). Благодаря встроенному в ядро щиту `Request`, данные из форм и URL уже очищены, и их можно выводить стандартными тегами.

```html
<!-- Файл: views/about.php -->
<div class="container my-5">
  <h1 class="fw-bold"><?= $title ?></h1>

  <div class="card shadow-sm mt-4">
    <div class="card-body">
      <p class="lead">
        <?= $info['description'] ?? 'Контент временно недоступен.' ?>
      </p>
    </div>
  </div>
</div>
```

### Шаг 4. Регистрация маршрута (Route)

Зарегистрируйте URL вашей страницы в файле `config/route.php`. Фреймворк поддерживает как статические пути, так и динамические параметры (например, `{id}` или `{slug}`):

```php
return [
    // ['URL-адрес', 'КлассController@метод', 'HTTP-метод']
    ['/', 'HomeController@index', 'GET'],
    ['/about', 'AboutController@about', 'GET'],
    ['/post/{id}', 'PostController@show', 'GET'], // Динамический роут, ID прилетит аргументом в метод show($id)
    ['/contact/submit', 'ContactController@submit', 'POST'],
];
```

## Развертывание на продакшен (Production Deploy)

* **Для серверов Apache:** В панели управления хостингом укажите корневую папку домена (Document Root) как `/public`. Главный файл `.htaccess` автоматически настроит ЧПУ.
* **Для серверов Nginx:** Используйте готовый шаблон настроек из файла `nginx.conf.example`.
* **Для Docker:** Выполните в корне команду `docker-compose up -d` для мгновенного поднятия изолированного контейнера с Nginx, PHP 8.4 и MySQL.

------------ОПИСАНИЕ РАБОТЫ ДАННОГО ДВИЖКА------------
Этот движок разделяет логику (работу с БД) и отображение (HTML).
Ты создаёшь контроллер — в нём пишешь запросы к БД и логику, отдаешь через render виду (view/about.php)
Создаёшь вид (view) — отображение на экране HTML или вывод данных из бд.
Движок сам подставляет шапку, title и подвал из `layout/main.php`.

При создании view можно использовать встроенный и подключеный bootstrap и font Awesome.



------------АЛГОРИТМ НАСТРОЙКИ И ИСПОЛЬЗОВАНИЯ------------
1. Из папки config выбрать тип подключения (mysqli.php или PDO.php), подключить БД в index.php в корневом в каталоге
2. В views/ создать представление для статичных html страниц или страниц с выводом данных из БД как пример (about.php).
3. Создать по шаблону файл логики в папке controllers:
